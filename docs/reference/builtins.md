# Appendix C — Built-in Runtime Functions

| Function | Returns | Purpose |
| --- | --- | --- |
| `typeof(value)` | `String` | runtime type name |
| `isany(value)` | `Boolean` | whether runtime type is `any` |
| `print(...)` | — | output used by project examples |

Exact `print` arity/formatting should be verified from source and tests.
