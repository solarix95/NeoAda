# Appendix F — NeoAda for Ada Programmers

NeoAda is Ada95-inspired, not Ada. Familiar elements include `if/elsif/end if`, `for`/`while` loops, procedures/functions, `begin/exception/end`, `others`, and `--` comments.

Important differences currently documented: NeoAda is an embedded scripting language; containers/methods/addons are central; `out` currently behaves more like Ada `in out`; separate `in out` syntax is not documented; and NeoAda provides `finally`.

Use Ada knowledge as a readability guide, not as an implicit NeoAda specification.
