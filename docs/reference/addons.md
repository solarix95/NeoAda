# Appendix D — Standard Addons

- **Ada.String** — case conversion, search, replacement, split, trimming, slice/chop, formatting, byte conversion.
- **Ada.List** — size, append/extend, insert, take/remove, search, sort, reverse.
- **Ada.Dict** — dictionary helpers.
- **Ada.Bytes** — binary-buffer operations.
- **Ada.Text.Encoding** — explicit `String`/`Bytes` conversion.
- **Ada.Math** — constants, rounding, powers, logs, trig, clamp, NaN/Inf checks.
- **Ada.Io.File / Ada.Io** — binary and text files.
- **Ada.DateTime** — dates, times, parsing, formatting, simple arithmetic.

Keep exact signatures synchronized with implementation and unit tests.
