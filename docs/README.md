# Programming in NeoAda

*A beginner-friendly guide to the NeoAda programming language*

This documentation accompanies NeoAda, an Ada95-inspired scripting language
and interpreter for embedding strongly typed scripts in C++ applications.

The book is designed for first-time programmers, technical users, Ada/C++
developers, and readers interested in predictable, high-integrity software
design.
