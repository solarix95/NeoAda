# Preface

Programming languages are often introduced from one of two directions. Some tutorials begin with computer-science terminology and assume that the reader already understands programming. Others simplify so aggressively that the reader later has to unlearn habits when programs become larger.

NeoAda provides an opportunity to take a different path. Its Ada-inspired syntax encourages programs that state their intent clearly. Variables are declared. Types are visible. Blocks have explicit endings. Exceptions are named. At the same time, NeoAda is a scripting language that can be embedded into C++ and extended by the host.

## Who this book is for

- first-time programmers, including students and young learners;
- Ada and C++ programmers who want to learn NeoAda quickly;
- application developers who want a small embedded scripting language with explicit, predictable semantics.

No previous programming language is required for Parts I and II.

## What this book is — and is not

This is a tutorial and programming guide, not a language standard. The current NeoAda implementation and unit tests remain authoritative. The chapters on high-integrity programming discuss design practices; they do **not** claim that NeoAda is certified for a safety standard or application domain.

## How to read it

If this is your first language, read the chapters in order and type the examples yourself. Experienced programmers can skim Part I and focus on procedures, containers, exceptions, value semantics, addons, and C++ embedding.
