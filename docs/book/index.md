# Programming in NeoAda

## A Beginner-Friendly Guide to the NeoAda Programming Language

NeoAda is a small, readable scripting language inspired by Ada95. It combines explicit declarations and strong typing with features expected from a modern embedded scripting language: containers, methods, exceptions, addons, and a C++ host API.

This book teaches the language progressively. The early chapters assume no programming experience. Later chapters explain design practices for predictable programs and embedding NeoAda into C++ applications.
